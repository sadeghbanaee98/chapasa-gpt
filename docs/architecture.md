# Chapasa GPT Architecture

## Stack
- Next.js + TypeScript frontend
- Tailwind + shadcn/ui design system
- RTL Persian interface
- Backend services for orders, files, pricing and payments
- PostgreSQL + Prisma
- Docker deployment

## Product Modules
- Landing page
- Print configurator
- File upload and PDF analysis
- Pricing engine
- Customer dashboard
- Admin dashboard
- Payment gateway
- GROQ AI print assistant

## Development Rules
- Keep all versions in Git history
- Production-first architecture
- Secure server-side pricing calculations
