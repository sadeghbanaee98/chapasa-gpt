# Hosting Requirements

## Recommended Production Setup
- Linux VPS
- Docker + Docker Compose
- PostgreSQL database
- Node.js runtime
- Nginx reverse proxy
- SSL certificate

## Required Environment Variables
- DATABASE_URL
- AUTH_SECRET
- PAYMENT_GATEWAY_KEYS
- GROQ_API_KEY
- STORAGE_CONFIG

## Deployment checklist
- Build frontend
- Run migrations
- Configure storage
- Configure domain
- Enable SSL
- Run health checks
